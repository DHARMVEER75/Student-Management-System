# Student Management System

## 📌 Project Overview
Student Management System is a web-based application developed using Java Servlets. It allows users to manage student records efficiently by performing CRUD operations.

## ✨ Features
- Add Student
- Update Student
- Search Student
- Delete Student
- View All Students
- User Login & Logout

## 🛠️ Technologies Used
- Java
- Servlets
- HTML
- CSS
- Oracle Database
- WebLogic Server

## 📂 Project Structure
- Java Servlets
- HTML Pages
- WEB-INF
- web.xml

## 🚀 How to Run
1. Clone the repository.
2. Configure Oracle Database.
3. Deploy the project on WebLogic Server.
4. Open the application in your browser.
